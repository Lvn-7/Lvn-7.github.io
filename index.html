Piper X 机械臂模仿学习全流程系统构建与 ACT 真机部署

  • 搭建 Piper X 主从遥操作系统与双视角数据采集系统，设计自定义数据规范并完成向标准 LeRobotDataset 的转换与本体配置调整、训练接口适配，形成稳定的真实机器人示教数据采集完整链路。项目已部分开源，涉及系统内保密。
  • 基于 LeRobot ACT 在 NVIDIA H100 单卡完成策略训练，并搭建服务器远程推理架构：机器人端通过 Wi-Fi 实时上传图像与 State，服务器返回 Action Chunk 驱动真机执行，完成独立地从数采、训练到部署控制的完整闭环。
  • 自行设计算法进行模型产出的后处理以及控制层算法再优化，最终在接近训练初始分布的旋钮操作场景中，真机任务成功率约 90%（已附 DEMO）；进一步分析发现，策略在分布外初始状态下的泛化能力主要受示教数据初始覆盖度限制。

Piper X 机械臂 PI0.5 VLA 微调与本体适配

  • 面向 Piper X 本体适配，完成 LeRobot 数据向 OpenPI / PI0.5 格式转换，设计 Observation / Action 映射、状态维度与动作空间配置，打通自定义机械臂接入预训练 VLA 的训练链路。
  • 基于官方 pi0.5_base 在 NVIDIA H100 单卡完成微调训练，采用视觉编码器全量训练 + PaliGemma / Action Expert LoRA 的混合微调与ViT / PaliGemma / Action Expert 全 LoRA 轻量微调两种训练方案开展训练。
  • 面向真机部署完成 Action Chunk 后处理及关节状态约束等控制优化，在当前小规模数据集下任务成功率约 50%；但泛化性依旧较弱，主要瓶颈为示教数据量及初始状态覆盖不足，相关真机测试DEMO 已展示于个人主页。

基于 ROS 2 的 Nova 2 灵巧手遥操作系统搭建与 G1 真机部署

  • 搭建基于 SenseGlove Nova 2 的跨主机灵巧手遥操作系统，在 Windows 端完成手套数据采集与配套上位机开发，通过 UDP 实时传输至 Ubuntu / ROS 2 端，实现动作映射与灵巧手实时控制。
  • 完成 BrainCo Revo2、Inspire 灵巧手的适配与联调，支持左右手及双手遥操作，并在 MuJoCo 仿真环境下完成动作验证及相关套件。
  • 将遥操作系统部署至 Unitree G1，完成从手套输入到独立机器人灵巧手执行的完整真机控制链路。项目已开源发布 ↗。

面向 GR00T N1.7 / SONIC 的 G1 全身遥操作与数据采集

  • 面向 Unitree G1 人形机器人全身操作学习，搭建基于 Pico、灵巧手与相机的遥操作及数据采集系统，实现机器人全身与灵巧手协同遥操作。
  • 打通全身遥操作与多模态数据采集链路，完成相机、手部及机器人状态等数据的统一记录，目前已进入任务示教数据采集阶段。
  • 计划基于采集数据开展 SONIC / GR00T N1.7 模型适配与微调，并进一步验证人形机器人全身操作任务的真机部署效果。
